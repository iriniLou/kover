# Kover — ковёр для рабочего стола

Ковёр лежит прямо на рабочем столе и прячет под собой бардак из папок и файлов.
Работает на **macOS** и **Windows**.

- возьми ковёр **за середину** и тащи — он переедет целиком;
- потяни **за край или уголок** — ковёр задерётся и сомнётся складками, как настоящий;
  отпустишь — так и останется мятым (с зажатым ⌥ Option / Alt можно мять за любое место);
- **двойной клик** — расправить ковёр;
- **колесо мыши** (или два пальца на тачпаде) над ковром — повернуть;
- **Ctrl / ⌘ + колесо** (или щипок на тачпаде) — сделать больше или меньше;
- **правая кнопка** по ковру — меню: расправить, положить ровно, размер, «во весь стол», ещё один ковёр, убрать;
- значок ковра в строке меню (Mac) или в трее у часов (Windows) — показать/спрятать ковры, автозапуск, выход.

Положение, размер и даже складки ковров запоминаются между запусками.

## Скачать

Готовые файлы — на странице **Releases** этого репозитория:

- `Kover-…-mac.dmg` — для Mac (Intel и Apple Silicon);
- `Kover-Setup-….exe` — для Windows.

### Mac: первый запуск

Программа не подписана сертификатом Apple, поэтому macOS при первом запуске её не пустит.

1. Откройте `.dmg` и перетащите **Kover** в папку «Программы».
2. Запустите Kover. Появится окно «не удалось проверить» — нажмите **Готово**.
3. Откройте **Системные настройки → Конфиденциальность и безопасность**, внизу будет
   «Kover заблокирован» — нажмите **Всё равно открыть** и подтвердите паролем.

Если пишет «приложение повреждено», выполните в Терминале:

```
xattr -cr /Applications/Kover.app
```

### Windows: первый запуск

Запустите `Kover-Setup-….exe`. Если появится синее окно SmartScreen —
нажмите **Подробнее → Выполнить в любом случае**.

## Сборка из исходников

```
npm install
npm start          # запустить
npm run dist:mac   # собрать .dmg (на Mac)
npm run dist:win   # собрать .exe (на Windows)
```

Сборки для обеих систем делаются автоматически в GitHub Actions
(`.github/workflows/build.yml`); при пуше в `master` файлы прикрепляются к релизу с номером версии из `package.json`.

Как устроено: на каждом мониторе — прозрачное окно во весь экран, клики мимо ковра проходят насквозь.
Ковёр — сетка из ~1000 точек с физикой ткани (`src/cloth.js`: гравитация, трение о пол, ткань не проходит
сквозь себя), рисуется через WebGL с освещением складок и тенью (`src/overlay.js`).

Картинку ковра можно заменить: `src/rug.jpg` (пропорции задаются константой `RUG_ASPECT` в `src/main.js` и `src/overlay.js`).
